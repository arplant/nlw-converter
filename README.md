# nlw-converter

## Convert bibliography data from the National Library of Wales

Many thanks to the National Library of Wales for their work and for providing their data under Creative Commons licences.

Datasets:
-  [Bibliography of Welsh Printed Material](https://www.library.wales/catalogues-searching/catalogues/specialist-catalogues/bibliography-of-welsh-printed-material). Copyright NLW, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.en).

Code generation assisted by a local instance of qwen3.5:4b (d8b0f5e9760c) and gpt-oss:20b (f38aa0c53da5) using Ollama and Claude Code harnesses.
